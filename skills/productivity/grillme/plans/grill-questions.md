# Grill bank

Pull from here when user hand-waves.

## On libraries / tools
- What does this library actually do? In one sentence.
- Why this one and not the built-in?
- What happens if you remove it?

## On data flow
- Where does the data start?
- Where is it stored?
- Who reads it back?
- What format on the wire?

## On features
- What is the smallest version that proves it works?
- What is the failure case?
- Who clicks what to trigger this?

## On architecture
- Why a new file?
- Why a new route?
- What existing thing does this duplicate?

## On AI-generated code
- Point at this line — explain it to me.
- What happens if the input is empty?
- What happens if two users do this at once?
